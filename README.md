# Responsive Image Gallery

This project is a responsive image gallery created using HTML and CSS. 
It displays different web projects as images with links, arranged in a grid layout.

## Features

* Responsive design for mobile and desktop
* 3-column layout on larger screens
* Automatically switches to 1-column layout on smaller devices
* Each image acts as a clickable link to a project
* Clean gradient background with simple UI

## Technologies Used

* HTML5
* CSS3 (Grid / Flexbox)

## Project Structure

* `index.html` – main gallery page
* `style.css` – styling for layout and responsiveness
* `images/` – contains all gallery images

## How It Works

The gallery uses CSS layout techniques to arrange images in rows and columns. 
On desktop screens, images are displayed in three columns. 
On smaller screens, the layout adjusts to a single column for better readability.
